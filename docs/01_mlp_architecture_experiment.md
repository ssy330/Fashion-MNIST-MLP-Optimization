# MLP 구조 실험 계획

## 0. 실험 개요 및 공통 설정

본 실험은 Fashion-MNIST 데이터셋을 대상으로 다층 퍼셉트론(Multi-Layer Perceptron, MLP)의 은닉층 너비, 깊이, 전체 학습 파라미터 수 및 은닉층별 뉴런 배치 형태가 분류 성능에 미치는 영향을 분석하는 것을 목적으로 한다. 모든 실험에서는 데이터셋, 전처리 과정 및 학습 조건을 동일하게 유지하고, `hidden_size_list`로 정의되는 모델 구조만 변경한다.

### 0.1 데이터셋 및 데이터 분할

Fashion-MNIST는 10개 의류 범주로 구성된 회색조 이미지 데이터셋이다. 원본 학습 데이터 60,000개는 계층화 무작위 분할(Stratified Random Split)을 통해 학습 데이터 50,000개와 검증 데이터 10,000개로 나눈다. 별도로 제공되는 테스트 데이터 10,000개는 전체 구조 탐색이 종료된 뒤 최종 선택 모델을 평가하는 용도로만 사용한다.

| 항목 | 설정 |
|---|---|
| 데이터셋 | Fashion-MNIST |
| 원본 학습 데이터 | 60,000개 |
| 학습 데이터 | 50,000개 |
| 검증 데이터 | 10,000개 |
| 테스트 데이터 | 10,000개 |
| 분할 방식 | Stratified Random Split |
| 분할 시드 | 42 |
| 입력 전처리 | 28 × 28 이미지를 784차원 벡터로 평탄화 |
| 정규화 | 픽셀 값 0~255를 0~1 범위로 변환 |
| 출력 클래스 수 | 10 |

### 0.2 학습 조건 및 재현성

난수 시드는 42로 고정하고, 각 모델의 학습 직전에 다시 설정하여 실험 결과의 재현성을 확보한다. 다만 구조에 따라 가중치 행렬의 크기가 달라지므로, 동일한 시드가 모든 구조에서 동일한 초기 가중치 값을 의미하지는 않는다.

| 파라미터 | 고정 값 |
|---|---|
| 입력 차원 / 출력 차원 | 784 / 10 |
| 활성화 함수 | ReLU |
| 가중치 초기화 | He 초기화 |
| 가중치 감쇠 계수 | 0 |
| Dropout / Batch Normalization | 미사용 |
| 최대 에포크 수 | 500 |
| 미니배치 크기 | 100 |
| 최적화 알고리즘 | Adam |
| 학습률 | 0.001 |
| Adam 계수 | beta1 = 0.9, beta2 = 0.999 |

검증 손실을 기준으로 조기 종료를 적용하며, 최대 학습 횟수는 500 에포크로 설정한다. 검증 손실이 직전 최적값보다 0.001 이상 개선되지 않는 상태가 10회 연속 발생하면 학습을 종료한다. 검증 손실이 개선된 시점의 모델을 저장하고, 저장된 모델의 검증 정확도를 구조 간 성능 비교에 사용한다. 각 실험 구조에 대해 학습 정확도, 검증 정확도, 학습 시간 및 실제 총 파라미터 수를 기록한다.

## 1. 실험 1: 은닉층 너비와 깊이의 영향

### 1.1 목적

은닉층의 너비와 깊이에 따라 MLP의 Fashion-MNIST 분류 성능이 어떻게 변화하는지 분석한다. 이 실험에서는 전체 파라미터 수를 통제하지 않으므로, 너비 및 깊이 증가에 따른 모델 용량의 변화를 함께 관찰한다.

### 1.2 실험 설계

| 항목 | 설정 |
|---|---|
| 은닉층 너비 | 16, 32, 64, 128, 256, 512 |
| 은닉층 깊이 | 1~5개 |
| 은닉층 구성 | 모든 은닉층에 동일한 너비 적용 |
| 전체 파라미터 수 | 통제하지 않음 |
| 실험 구조 수 | 30개 |
| 실행 파일 | `01A_width_depth.py` |

각 구조는 너비 `w`와 깊이 `d`에 대해 `[w, w, ..., w]` 형태로 구성한다. 예를 들어 `[128, 128, 128]`은 128개 뉴런을 갖는 은닉층 3개로 이루어진 모델을 의미한다. 총 6개의 너비와 5개의 깊이 조합으로 30개 구조를 학습한다.

### 1.3 분석 및 시각화

- 그래프 A: 은닉층 너비를 x축(log2 스케일), 검증 정확도를 y축으로 하고, 깊이별로 선 그래프를 작성한다.
- 그래프 B: 은닉층 깊이를 x축, 검증 정확도를 y축으로 하고, 너비별로 선 그래프를 작성한다.

분석 시 너비 증가에 따른 성능 포화 여부, 깊이에 따른 성능 변화 및 너비와 깊이 사이의 상호작용을 중점적으로 확인한다.

## 2. 실험 2: 동일 파라미터 예산에서 깊이와 너비 배분의 영향

### 2.1 목적

전체 학습 파라미터 수를 거의 동일하게 유지한 상태에서 은닉층의 깊이와 너비 배분이 MLP 성능에 미치는 영향을 분석한다. 이를 통해 단순한 모델 규모의 증가 효과를 분리하고, 동일한 계산 자원 내에서 적절한 깊이를 탐색한다.

### 2.2 실험 설계

| 항목 | 설정 |
|---|---|
| 파라미터 예산 | 50,000 / 100,000 / 200,000 / 400,000 |
| 은닉층 깊이 | 1~5개 |
| 은닉층 구성 | 모든 은닉층에 동일한 너비 적용 |
| 뉴런 수 | 목표 파라미터 예산에 맞춰 산정 |
| 허용 오차 | 목표 예산 대비 ±1% |
| 실험 구조 수 | 20개 |
| 실행 파일 | `01B_parameter_budget_depth.py` |

깊이별 은닉층 너비는 다음과 같이 설정한다. 표의 값은 각 은닉층에 동일하게 적용되는 뉴런 수이다.

| 깊이 | 50,000 | 100,000 | 200,000 | 400,000 |
|---|---:|---:|---:|---:|
| 1층 | 63 | 126 | 252 | 503 |
| 2층 | 59 | 110 | 201 | 349 |
| 3층 | 55 | 100 | 175 | 290 |
| 4층 | 52 | 93 | 157 | 256 |
| 5층 | 50 | 87 | 145 | 232 |

예를 들어 200,000개 예산의 3층 모델은 `[175, 175, 175]`으로 구성한다. 모든 조합은 실제 파라미터 수가 목표 예산의 ±1% 범위에 포함되는지 학습 전에 확인한다.

### 2.3 분석 및 시각화

파라미터 예산별로 은닉층 깊이를 x축, 검증 정확도를 y축으로 하는 선 그래프를 작성한다. 동일한 파라미터 예산에서 깊이에 따른 성능 변화와 예산 규모별 최적 깊이의 차이를 분석한다.

## 3. 실험 3: 은닉층 뉴런 배치 형태의 영향

### 3.1 목적

은닉층 수와 전체 파라미터 수를 거의 동일하게 유지할 때, 층별 뉴런 배치 형태가 MLP 성능에 미치는 영향을 분석한다. 은닉층 깊이는 3개로 고정하며, 네트워크 폭의 변화 방향에 따른 성능 차이를 비교한다.

### 3.2 실험 설계

| 항목 | 설정 |
|---|---|
| 은닉층 깊이 | 3개 고정 |
| 파라미터 예산 | 50,000 / 100,000 / 200,000 / 400,000 |
| 뉴런 수 범위 | 16~512의 정수 |
| 구조 유형 | 5개 |
| 예산별 조합 수 | 구조 유형당 1개 |
| 허용 오차 | 목표 예산 대비 ±1% |
| 실험 구조 수 | 20개 |
| 실행 파일 | `01C_neuron_layout.py` |

| 구조 유형 | 조건 |
|---|---|
| 균일형 (Uniform) | a = b = c |
| 증가형 (Increasing) | a < b < c |
| 감소형 (Decreasing) | a > b > c |
| 확장-축소형 (Expand–Contract) | a < b > c |
| 축소-확장형 (Contract–Expand) | a > b < c |

| 파라미터 예산 | 균일형 | 증가형 | 감소형 | 확장-축소형 | 축소-확장형 |
|---|---|---|---|---|---|
| 50,000 | 55-55-55 | 48-77-97 | 58-47-29 | 50-102-49 | 57-35-70 |
| 100,000 | 100-100-100 | 80-147-160 | 110-78-56 | 85-170-103 | 110-56-111 |
| 200,000 | 175-175-175 | 149-178-298 | 197-149-99 | 146-289-143 | 200-102-199 |
| 400,000 | 290-290-290 | 226-320-453 | 365-203-183 | 232-460-235 | 341-182-363 |

균일형의 네 구조는 실험 2에서 사용한 3층 구조와 동일하다. 따라서 전체 실험은 70개 구성을 포함하지만, 중복 구조를 제외한 실제 고유 구조 수는 66개이다.

### 3.3 분석 및 시각화

구조 유형을 x축, 검증 정확도를 y축으로 하는 막대그래프를 작성한다. 각 막대는 해당 구조 유형의 평균 검증 정확도를 나타내며, 평균은 네 가지 파라미터 예산에서 측정한 검증 정확도의 산술평균으로 계산한다. 또한 각 막대 위에는 파라미터 예산별 검증 정확도(50,000, 100,000, 200,000, 400,000)를 점으로 함께 표시하여, 구조 유형별 평균 성능과 예산 규모에 따른 성능 변화를 동시에 확인할 수 있도록 한다.

다만 해당 평균에는 서로 다른 파라미터 예산의 영향이 함께 포함된다. 따라서 구조 유형별 평균 성능은 특정 배치 유형의 본질적 우수성을 단정하는 근거가 아니라, 후속 분석을 위한 탐색적 비교 결과로 해석한다. 최종 모델은 전체 실험에서 검증 정확도가 가장 우수한 구조를 선정한 뒤, 테스트 데이터 10,000개를 사용하여 한 번만 평가한다.
