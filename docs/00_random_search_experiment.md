# Random Search 실험 결과 분석

| 순서 | 분석 질문 | 주요 분석 방법 |
|---|---|---|
| RQ1 | 특정 파라미터가 어떤 값일 때 성능이 대체로 좋은가 또는 나쁜가? | 파라미터 값별 평균·중앙값·표준편차 및 성능 분포 비교 |
| RQ2 | 상위·하위 성능 그룹에서 공통적으로 발견되는 파라미터 특징이 있는가? | 상위·하위 25%의 파라미터 출현 빈도 및 전체 대비 비율 비교 |
| RQ3 | 특정 파라미터의 효과가 다른 파라미터의 값에 따라 달라지는가? | 파라미터 쌍별 상호작용 분석 |
| RQ4 | 학습 시간이 과도하게 길어지는 데 영향을 주는 파라미터나 조합이 있는가? | 학습 시간, Epoch 수, Iteration 수, 모델 크기별 비교 |
| RQ5 | 높은 검증 성능을 달성한 모델 중에서도 과적합이 의심되는 모델이 있는가? 있다면 어떤 설정에서 주로 나타나는가? | 상위 성능 모델의 Train–Validation Gap 및 Loss 변화 분석 |
| RQ6 | Random Search 후보 중 제외하거나 특정 값으로 고정할 만한 파라미터가 있는가? | RQ1~RQ5 결과를 종합하여 후보별 유지·제외·고정 판단 |
